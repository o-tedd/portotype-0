# DEC-001 — Fundação React + TypeScript + Vite

## Status
Aceita

## Decisão
Usar React, TypeScript e Vite como base do frontend.

## Motivo
A combinação oferece desenvolvimento rápido, tipagem estática e uma base adequada para um projeto educacional e de portfólio.

## Consequências
- componentes serão escritos em TSX;
- TypeScript permanecerá em modo strict;
- Vite cuidará do ambiente de desenvolvimento e build.
